INSTRUCCIONES DE COMPILACIÓN Y EJECUCIÓN

Ubicarse  en la carpeta raíz ('lab04/')

1. COMPILACIÓN

Ejecutar el comando

javac -cp "src/algs4.jar" src/*.java


2. EJECUCIÓN

Para ejecutar el experimento con el comando:

En Linux / macOS:
  java -cp "src:src/algs4.jar" Experiment

En Windows:
  java -cp "src;src/algs4.jar" Experiment
